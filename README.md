# Hildur's Mountain Haven

Create a web application for 'Hotell Hjortronet' in Hemavan featuring their new AI receptionist 'Hildur 4.0'. The app should have a warm, northern Swedish alpine hotel design (cozy dark green, warm gold/amber, clean typography, dark/light mode toggle). Make it fully interactive using local state (no backend required).
Structure the app with a top header and a main navigation bar with 4 key sections/tabs:
1. Välkommen (Welcome View): A friendly, clever greeting from Hildur 4.0 (no longer rhyming or glitching!). Shows current hotel status: Weather, real Northern Lights forecast (Norrskenslarm - currently OFF unless active), and a cute status badge for 'Kjell the Hotel Cat (Status: Sleepy/Admin privileges revoked)'.
2. Gästtjänster (Guest Services): Interactively allows booking a Sauna slot (with a max capacity limit of 8 people to show safety!), ordering breakfast in bed, or reporting an issue.
3. Trygghet & Säkerhet (Security Promise): A visual security dashboard explaining how Hildur 4.0 protects guest data. Highlight 3 fixed vulnerabilities from Hildur 3000 (No public Wi-Fi passwords over speakers, Kjell is no longer Admin, encrypted guest data).
4. Drift & Infrastruktur (Relocation from Sauna): An interactive infographic view showing Hildur 4.0's move out of the sauna onto cloud infrastructure with a Raspberry Pi edge backup during power outages.
Include a language toggle (Svenska, Engelska, Samiska) and a fun Easter Egg button for 'Kjell Katten'. Make all buttons, forms, and tabs feel dynamic with toasts/popups.
